## Описание
Веб-страница «О себе», доработанная в рамках лабораторной работы №2 по теме
«Базовые и продвинутые возможности CSS» (вариант 18).
Тема: **«Космический энтузиаст и астроном-любитель»**

Страница из ЛР №1 оформлена с помощью внешнего CSS-файла `style.css`,
содержание (заголовки, текст, списки, форма, структура разделов) сохранено.

## Что реализовано

### Подключение стилей
- Основной CSS вынесен во внешний файл `style.css`
- 1 inline-стиль — `position: relative` на контейнере звёзд
- 1 правило во внутреннем блоке `<style>` — рамка и тень аватара

### CSS-переменные (`:root`)
- основной цвет — тёмно-синий
- акцентный цвет — золотой
- цвет текста и шрифт

### Позиционирование
- `static` — обычные блоки в потоке документа
- `relative` — контейнер звёзд и секция «Проекты»
- `absolute` — звёзды внутри контейнера

### Псевдоклассы и псевдоэлементы
- `:hover` на секции «Проекты» — звёзды разлетаются и гаснут
- `:active` на кнопке «Отправить» — эффект вспышки
- `:focus` на полях формы
- `:visited` на ссылке
- `::before` / `::after` — звёздное небо на фоне страницы и анимация звёзд у «Проектов»

### Дизайн и стилизация
- Звёздное небо на фоне всей страницы (CSS-градиенты + анимация мерцания)
- Цветовая гамма — тёмно-синяя с золотистыми акцентами (космическая эстетика)
- Текст и нумерованные/маркированные списки выровнены по центру
- Контрастность текста соблюдена (не менее 4.5:1)

## Технологии
- HTML5 (семантическая вёрстка)
- CSS3 (переменные, позиционирование, псевдоклассы, псевдоэлементы, анимации)
